A full-featured, luxury web application and store management portal built for **Brewbeans Karachi**, a cozy two-story specialty coffee sanctuary located at **Shop #6, Plot SB 1/SB 2, Rab Medical Center, Block 2 Gulshan-e-Iqbal, Karachi**.

---

## 🌟 Key Application Features

### 1. ☕ Multi-Page Experience
- **Home (`#home`):** Hero section featuring authentic storefront photography, ratings banner (4.9★ from 85+ Google & 269+ Foodpanda reviews), feature service pillars, bestseller drink showcase, and sanctuary atmosphere preview.
- **Artisan Menu & Direct Order (`#menu`):** Search, category filters (Hot, Iced, Frappes, Bakery, Beans), Sunday 40% OFF filter toggle, floating quick-checkout bar, and an interactive Custom Brew Studio banner.
- **Interactive Coffee Bar Customizer Modal:** Real-time visual cup simulator where patrons can choose their base espresso, specialty milk (Whole, Condensed, Barista Oat, Almond), syrup infusions, mascarpone cloud toppings, and temperature.
- **Table Reservation Loft Booking (`#booking`):** Reserve seating in the Ground Floor Barista Bar, 2nd Floor Loft Sanctuary, or Study Quiet Corner with date, time, and special requests.
- **Direct Website Checkout (`#checkout`):** Full checkout flow with **Cash on Delivery (COD)**, **Online Debit/Credit Card Gateway Modal**, and **Mobile Wallets (JazzCash / EasyPaisa / Raast)** with live validation and Karachi area selection.
- **Live Order & Rider Tracker (`#track`):** Real-time order progress stepper (Received → Brewing → Out for Delivery → Delivered) with live timestamps, delivery rider calling, and order receipt summary.
- **Sanctuary Story (`#about`):** History of Brewbeans Karachi, ethically sourced Arabica beans, roasting philosophy, and two-story community loft.
- **Contact, Hours & Community Reviews (`#contact`):** Google Maps integration, 9:00 AM – 4:00 AM opening hours, verified reviews carousel, and an interactive review submission form.

### 2. 🔒 Executive VIP Admin Management Portal (`#admin`)
- **Protected Access:** Secure login authentication (`admin` / `brewbeans123`).
- **Real-Time KPI Dashboard:** Total Sales (PKR), Active Orders count, Total Orders count, and Table Reservations.
- **Order Management:** Filter by status (Received, Brewing, Out for Delivery, Delivered), one-click status transitions, customer details, Karachi address, and payment confirmation (COD vs Online Card/EasyPaisa).
- **Table Reservation Center:** Manage upcoming guest reservations with guest count, floor location, occasion, and confirmation toggle.
- **Menu Catalog CRUD:** Add new drinks/desserts, select real image presets, adjust pricing, toggle stock status, and update descriptions.
- **Community Review Management:** Moderate and delete reviews.

## 🚀 Getting Started

### Prerequisites
- Node.js (v16.0 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Jasir-ali90/Brewbeans.git

# Navigate into the project directory
cd Brewbeans

# Install dependencies
npm install

# Start development server
npm start
```
The app will launch at `http://localhost:3000` (or `http://localhost:3008`).

### Production Build
```bash
npm run build
```
Creates an optimized production bundle in the `build/` directory.
