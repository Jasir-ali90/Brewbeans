## 🚀 Quick Deploy on Vercel

This repository is **100% pre-configured for Vercel deployment** with native SPA fallback routing (`vercel.json`), asset caching, and zero build errors.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Jasir-ali90/Brewbeans)

### 📌 Manual Vercel Deployment in 3 Steps:
1. Go to [Vercel Dashboard](https://vercel.com/dashboard) and click **"Add New Project"**.
2. Select your imported GitHub repository: `Jasir-ali90/Brewbeans`.
3. Keep default settings:
   - **Framework Preset:** `Create React App`
   - **Build Command:** `npm run build`
   - **Output Directory:** `build`
   - Click **Deploy**! ✨ Your site will be live on an ultra-fast global CDN in under 60 seconds.

## ⚡ Local Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (`v16.14.0` or higher)
- `npm` (`v8.0.0` or higher)

### 1. Clone & Enter Project
```bash
git clone https://github.com/Jasir-ali90/Brewbeans.git
cd Brewbeans
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Launch Development Server
```bash
npm start
```
Open your browser at `http://localhost:3008` (configured with `WDS_SOCKET_PORT=0` for zero WebSocket errors).

### 4. Build for Production
```bash
npm run build
```
Creates an optimized production bundle inside the `build/` directory ready for deployment.
